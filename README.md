# Lernanwendungen

Interaktive Simulationen und Übungen für den Unterricht, veröffentlicht über GitHub Pages.

- `index.html` – Startseite (Comic-Game-Design), liest die Liste aus `apps.js`
- `apps.js` – Liste aller Anwendungen (Titel, Fach, Thema, Klasse, Beschreibung, Pfad)
- `apps/<fach>/` – die einzelnen HTML-Anwendungen

Neue Anwendung: HTML-Datei nach `apps/<fach>/` legen und in `apps.js` eintragen.

Hinweis: Die Seite ist öffentlich – keine Schülerdaten hochladen.
